Classroom Booking
Версия: 1.0.0

Назначение:
Приложение для бронирования компьютерных аудиторий.

Системные требования:
- Windows 10/11
- .NET Desktop Runtime 10.0 или новее
- Разрешение экрана 1920x1080 (рекомендуется)

Установка:
1. Запустить ClassroomBooking_Setup_1.0.0.exe.
2. Следовать инструкциям мастера.
3. Запустить программу через ярлык.

Удаление:
Использовать стандартное удаление приложений Windows.

Конфигурация:
Настройки находятся в appsettings.json.
